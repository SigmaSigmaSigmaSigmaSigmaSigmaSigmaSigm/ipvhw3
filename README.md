# ipvhw3

Лабораторна робота №3. Teachinder: робота з DOM.

Запуск з папки роботи:

```bash
python3 -m http.server 8000
```

Відкрити http://localhost:8000.

Є перегляд викладача, обране, фільтри, пошук, сортування таблиці
та додавання викладача. Дані беруться з матеріалів другої роботи.
Зміни зберігаються тільки до перезавантаження сторінки.
Для фотографій з randomuser.me потрібен інтернет.
